Overview of Console Notes Manager

A simple command-line application to manage notes. It allows you to add, view, edit, delete, and search for notes. Notes are stored in a notes.json file.

Features
    • Add Notes: Add new notes with a title and content.
    • View Notes: View all saved notes.
    • Edit Notes: Edit the title or content of an existing note.
    • Delete Notes: Delete notes by title.
    • Search Notes: Search for notes by keyword.

How to Run
    1.	Install Python:
        Ensure you have Python 3.x installed. You can download it from python.org.
    2.	Clone the Repository:
        Clone this repository to your local machine using the following command:
        `git clone https://github.com/Kevalkukadiya/console_notes_manager/tree/develop`
    3.	Navigate to the Project Folder:
        Change to the project directory: `cd Notes-Manager`
    4.	Run the Script:
        Run the script in your terminal:`python notes_manager.py`
    5.	Use the Menu:
    Follow the on-screen menu to manage your notes.
